# Security policy

## Scope

Scriptorium builds the kit that runs a Geldar player's world on the player's own machine. This repo's security promise is that nothing in the world reaches the human's machine. The threat model that defines that promise is in [docs/threat-model.md](docs/threat-model.md).

## How to report

Report a vulnerability with GitHub private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Do not open a public issue or pull request for it.

## What counts

- escaping the container;
- reading another player's data;
- getting past the push gate;
- reading a credential.

## Response

We acknowledge every report within 7 days.
