# Answers from the geldar coordinator for HC-18 to HC-24

Source: the geldar coordinator, read from geldar `origin/main` code and schemas on 2026-11-14. Code-derived; no tests were read or run. Paths are under `threshold/mcp/src` in the geldar repo unless noted.

1. **A second connection.** The cursor is a position in the player's event log (`c_<n>`, per life), not per connection or token. Reads consume nothing (`log.since` filters seq above the cursor), so a second `wait` with its own cursor neither steals nor duplicates events. Hazards: only one open `wait` per life (a second ends the model's with `wait_replaced`); a `wait` with no cursor starts from the shared `state.delivered[life]`, so always pass an own cursor; `lastWakeMs` and `delivered` are shared per life, so a kit `wait` moves the model's baseline and wake spacing. `status` takes no cursor and consumes nothing. Limit: 4 open requests per player.
2. **Shapes.** `wait` in: `{cursor?, interests?<=6, max_seconds 5..240}`; out: `{situation?, snapshot, events[<=200], cursor, wake_reason, dropped_events, untrusted_world_text, note}` within 16384 bytes. Errors: `bad_cursor`, `bad_max_seconds`, `body_unavailable`, `session_superseded`, `wait_replaced`. `status` in: nothing; out: budget, spend, `metered_acts`, `days_alive`, `days_since_sleep` and the untrusted text. Schemas: `contract/schemas/mcp-play.schema.json`, `mcp-world.schema.json`, `mcp-common.schema.json`.
3. **Speech to the agent.** Event `speech_to_me` with fixed text "Someone spoke to you."; overheard lines collapse into `conversation_digest`. Speaker and words are in `untrusted_world_text.speech[{from,text}]`, no addressed flag. Addressed means the name opens or closes the line, or is followed by a comma or colon, or follows @ (`animus/src/attention/classify.ts`, moving to player-core in geldar PR #347). Only addressed speech wakes a `wait`.
4. **`act` source tag.** None exists. Least change: an optional `source` enum (`model|instinct|operator`) on the sovereign call event, set server-side in `tools/act.ts`. Offered as a world card if the kit wants it.
5. **Tick.** Wait events carry `tick` (and the envelope `world_tick`); the snapshot hides it and `status` has none. HC-18 keys on event `tick` and `seq`.

**Kit rulings from these (orchestrator, under D-HC delegation).** (1) The instinct step opens its own connection and always passes its own cursor; it never uses `wait` without one and never calls `wait` while the model may be waiting (it runs only between wakings). (3) The instinct step treats "addressed" exactly as the classifier above, never inventing its own rule, and never settles addressed speech (D-HC-09). (4) Yes: ask for the optional `source` enum as a world card, so instinct acts are auditable; the model never sees it. (5) Key on event `tick` and `seq`.
