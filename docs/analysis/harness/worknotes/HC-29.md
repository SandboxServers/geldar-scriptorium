## Other deviations

- **Quote character.** The packet shape is `About "NAME": ...`. `sanitizeFact` replaces every `"` with `'`, including the wrapper quotes, so a `"`-wrapped line cannot pass `sanitizeFact(line, MAX_FACT_CHARS)` unchanged. The name is therefore quoted with `'`: `About 'NAME': <bank> <UNSURE>`. The hostile-name test checks this form.
- **Name cap.** The packet does not cap the name. It is capped at 32 characters so that `UNSURE` always fits in the line. An empty name after cleaning shows as `unnamed`.
- **`renderLine` is exported.** The packet's shapes export it. It returns placeholder text without the `enabled` gate. Nothing in this commit calls it outside `facts.ts`, and `index.ts` (HC-30a) does not exist yet. HC-30a must reach the agent only through `nearbyFacts` with `enabled` set from its env switch, and must not call `renderLine` directly. This is recorded for the orchestrator.
- **`enabled` is required.** The packet signature has no default, so the "no enabled" case in the test is covered by passing `false`.
- **`nearbyFacts` filters by `nearby` ids** against each model's `other` id before selection. This follows the packet's `nearby` argument.
